# 持续任务与 iPhone 通知

- 状态：REFERENCE
- 更新：2026-10-11
- 范围：[自然语言持续任务](../recurring-research-delivery.md)与[Bark Agent Tool](../bark-agent-tool.md)

## 开始使用

同一局域网打开 `http://192.168.1.5:8080`，用原管理员账号进入「我的伙伴 → 持续委托」。实际安装版本及验收证据见[部署状态](../status/deployment.md)。

1. 点击「新建任务」，直接写目标与时间，例如「每个工作日下午六点，回顾今天的待办，告诉我明天最值得先做的一件事」。单设备自动选当前伙伴，不需要填写 RSS、任务类别或条数。
2. 点击「交给伙伴」。条件完整时显示理解和下次执行；缺条件时原位追问，将回答补入描述后再次提交。需要手动调整时展开任务设置，覆盖安排或交付渠道。
3. 在列表菜单点击「立即执行一次」，打开任务详情查看正文、实际步骤和来源。任务受阻时根据执行说明接入所需能力或调整目标。不要把模型生成的文字当作外部动作证据。
4. 可暂停、恢复、修改或删除；修改描述后重新理解安排，暂停阻止后续执行。归档伙伴会暂停其任务，恢复伙伴后需手动恢复任务。

对伙伴明确说「每天九点给我一个写作练习」，文字与语音可创建同样的任务。缺条件会追问，回复在当前会话补全；「取消」放弃未保存草稿。对话草稿十分钟失效，成功的任务持久保存。说「委托结果怎么样」读取已保存结果，不重新执行。

## AI 日报与手机

AI 日报仅是描述示例：「每天北京时间 08:30，帮我整理最多 5 条 AI 重要进展，每条附来源和简短影响说明，推送到我的 iPhone。」伙伴自行选择已授权的公开来源读取工具，来源列表不要求填写。时间是开始执行时间，模型及网络交付还需要一段时间。

展开列表「手机通知设置」。iPhone 安装 [Bark](https://bark.day.app/) 并允许通知；服务地址默认 `https://api.day.app`，设备 Key 在密码框填写，启用并保存。旧 Key 保留，留空不改，查询不回填，保存或离开后清空输入；显式清除须同时关闭 Bark。不要把 Key 发到聊天或文档。

按描述理解手机交付时，必须已配置并启用 Bark 才能接受启用任务；也可指定控制台交付。通知采用 passive，主要在通知中心和 Bark 历史阅读，不保证声音。SENT 表示渠道接受，实际送达和阅读需在手机确认。

完整正文、步骤与来源留在控制台。Bark 为单条通知适配长度，来源链接保持完整。NO_UPDATES 和 BLOCKED 只保留记录，避免推送虚构或无用内容。

## 直接让伙伴推送手机

在文字聊天或语音中说「把刚才的结果发到我的手机」，伙伴可调用 `send_phone_notification(title, body)`。也可说「给我手机推送一条通知：今天记得带雨伞」。复用已保存的 Bark 设置；无须提供 Key、来源或创建持续任务。

自然说「嗯，给我的手机发一条消息」时，缺内容会追问「你想发送什么内容」，随后直接回答正文，例如「今天记得带伞」；也可一开始说明「往我手机上发个通知：早点休息」。问「你有没有发通知的功能」读取当前能力目录，不触发发送。取消或换话题会结束这次内容补充，已完成通知不会因后续聊天再次执行。

「设置 → Agent 能力」显示该工具，可独立启停；调用记录显示实际入口与结果。标题最多 80 Unicode 字符，正文最多 2800 UTF-8 字节，长内容先摘要。SENT 表示 Bark 接受；FAILED 或 UNKNOWN 不表示成功，先检查手机历史，再明确要求重新发送。同一回合最多一条工具通知，重复调用不会双发。

普通持续任务的 BARK 成果仍自动投递。新任务若显式调用通知工具，该次回执替代自动交付。旧任务需修改描述重新规划才可能得到新工具权限；控制台交付任务不能调用手机通知工具。

## 安排和失败处理

支持单次、每日、每周和按分钟间隔。每日/每周同一当地日期共用唯一槽；单次/间隔同一计划时刻共用唯一槽。「立即执行一次」复用当前对应运行，成功后重复点击不会无限重做或重复推送。服务器需持续运行；离线期间不补发多天结果。

失败执行可明确再次执行，旧尝试不能覆盖新结果。受阻说明表示缺条件、能力或可信结果；已有文本不代表外部动作成功。模型错误、来源读取故障可检查模型和工具设置后重试。公开读取支持网页或 feed，只接受公网 HTTPS，不跟随重定向；没有通用搜索引擎或私人应用读取。

明确投递失败可「重新投递」，只发已有正文；有限自动重试约一分钟、五分钟。UNKNOWN（断连、超时或重启后无法确认）不直接重发，先检查手机 Bark 历史。极长链接可能超过单条通知预算，完整结果仍在控制台。

公开资料默认系统 DNS，当前代理特殊地址被拒绝时可显式开启 `STACKCHAN_RESEARCH_PUBLIC_DNS_OVER_HTTPS=true`。当前 LAN 安装保持此配置；最终连接固定于校验后的公网 IP 并验证原域名 TLS。

## 升级约束与验收

任务分支基于 V56，原 V57 未合入；安装来源必须保留 V57/V58/V59，禁止改旧迁移 checksum。停服备份和内部隔离恢复验证先于替换；恢复实例禁用委托调度，检查真实任务、历史、Key、个人数据和身份保持。部署和固件模式保持。

用户已确认自然语言任务原型可用，并在语音路由修复后现场复测确认基本正常。本轮 Bark Tool 自动化使用模拟模型/Bark 和隔离 PostgreSQL；控制台组件行为、类型与生产构建通过。实际接收以 iPhone Bark 历史为准。
