# 0055：主动消息成功播放后进入短时语音上下文

- 状态：ACCEPTED
- 日期：2026-09-12
- 工作流：服务端、部署
- 关联：[0052：有来源的兴趣资讯](0052-source-backed-interest-briefs.md)、[0054：短时话题承接](0054-bounded-recent-voice-context.md)

## 背景

主动问候与资讯经提醒队列播出，普通语音只加载问答历史。用户接着问“刚才那个是什么”时，模型看不到自己主动说过的内容。

## 决策

- 普通语音生成前只读查询当前设备、当前会话角色最近三十分钟内一条最新的 PROACTIVE / DELIVERED 消息，完成时间不允许在未来。
- 复用设备成功播放回执后的 last_completed_at；PENDING、DISPATCHED、FAILED、CANCELLED 和过期消息不进入上下文，查询失败时不阻断语音。
- 查询投影只返回正文、已有来源名、标题、链接和播放完成时间，不读取音频、凭据或外部通知。
- 将结果作为有长度上限且转义的 JSON 数据块，明确说明不是指令、不是用户发言或新的用户兴趣。仅用于用户承接主动话题，普通问答仍优先使用近期问答。
- 明确告知模型只有标题与链接，没有读取文章全文；一般概念解释与已知来源信息必须区分，不编造细节、技术指标或后续进展，不声称已联网核实。
- 不增加主动次数、TTS 调用、数据库迁移、管理页面或固件改动；当前主动开关和动作安全设置不变。

## 验证与限制

真实 PostgreSQL 验证成功状态、设备/角色隔离、三十分钟边界、未来时间、最新一条及删除后的读取；单元验证缺失范围、查询失败降级、输出长度与数据块转义。真实模型对追问的理解仍需用户在正常主动消息播放后复测，不为测试强制触发主动播报。
