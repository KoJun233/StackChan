# 0058：明确转题、纠正和续讲使用可验证的语音对话边界

- 状态：ACCEPTED
- 日期：2026-09-13
- 工作流：服务端
- 关联：[功能评审 D01](../feature-review-2026-09-13.md)、[0054](0054-bounded-recent-voice-context.md)、[0055](0055-delivered-proactive-conversation-context.md)

## 决策

- 识别明确的转题指令、带明确新对象的纠正表达和简短续讲指令；否定、引用或询问指令含义不作为控制指令。原话仍完整保存，不允许自由模型输出修改对话边界。
- V50 在会话保存 `voice_topic_reset_at`。明确转题后只使用该边界起的新用户轮次，旧主动消息也不得再次进入上下文；不删除聊天记录或长期记忆。时间戳来自已持久化本次用户消息，重复调用幂等。
- 转题或明确纠正同时取消本会话待确认的语音操作，之后的“好的”不能执行旧操作。新话题仍可以产生新的确认式提案，不能绕过确认。
- 纠正保留必要历史供模型理解，但当前明确新对象优先用于事实工具路由；续讲要求沿上次实际保存的回答推进，没有近期对话或有效主动上下文时确定性澄清且不调用模型、不提取记忆，动态事实仍需对应工具。
- 近期三十分钟/四轮上限、角色隔离、单次 TTS/单 WAV、取消与隐私边界保持不变；实际措辞质量需要实体对话验证。

## 验收

验证当前转题、转题后的后续轮次、重启后持久边界、旧主动消息排除、记录保留、待确认操作取消、明确纠正工具选择、续讲事实授权和否定/引用负例。运行语音/Agent 定向测试、真实 PostgreSQL 迁移/持久化及服务端回归。
