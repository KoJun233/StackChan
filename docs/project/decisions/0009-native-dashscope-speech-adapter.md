# 0009：服务端增加阿里云百炼原生语音适配器

- 状态：ACCEPTED
- 日期：2026-07-19
- 工作流：服务端、前端
- 相关提交：`121ed8e`

## 背景

现有语音运行时只支持 OpenAI-compatible HTTP 音频接口。阿里云百炼的 Fun-ASR 使用 WebSocket 双工事件协议，Qwen-Audio-TTS 使用供应商原生 HTTP 请求并返回临时音频 URL，无法仅通过管理员修改基础地址兼容。

## 决策

保留 OpenAI-compatible 适配器，并在服务端增加显式 `DASHSCOPE` 提供方。百炼端点只能由经过格式限制的 Workspace ID 与固定华北 2 域名构造；ASR 在服务端完成 WAV 到实时 PCM WebSocket 的转换，TTS 在服务端调用原生接口并从严格允许的结果主机下载 WAV。供应商凭据不下发设备。

## 原因

供应商协议差异属于服务端适配职责。这样可以保持固件协议稳定、密钥集中加密、提醒与语音回合复用相同 TTS 实现，同时避免让管理员输入任意 WSS、下载地址或认证载荷。

## 影响

语音配置 API 和数据库增加提供方类型与 Workspace ID。百炼模式首版只支持华北 2；扩展地域前必须验证对应的 ASR/TTS 域名和结果下载主机。测试连接会执行一次 TTS 和一次 ASR 调用，可能消耗少量供应商试用额度。
