# ADR0075：Bark 手机通知成为 Agent 工具

- 状态：ACCEPTED
- 日期：2026-10-11
- 关联：[COMPANION-010](../bark-agent-tool.md)

## 背景

用户已确认自然语言通用任务原型可用，要求复用已有 Bark 集成，封装成 Agent 可以调用的推送 Tool。

## 决策

新增 `send_phone_notification(title, body)`，收件渠道由服务端已有加密配置决定。接入内置工具注册、管理开关、调用审计与后台授权快照；当前明确推送请求才开放聊天写工具，旧任务不继承新写权限。

通知请求与通知能力咨询均进入工具 Agent；咨询只读当前配置授权目录，不授予写权限。角色与工具边界使用 system prompt，实际目录优先于旧聊天否认；缺正文且未操作时追问内容，只有紧接的正文补全延续此次授权，取消或换话题即结束。

返回真实 SENT/FAILED/UNKNOWN，失败和不确定状态不记成功。V60 只追加不可逆操作/内容指纹与回执，外发前独立提交标记，同一服务端回合或运行最多一次工具外发。后台实际工具回执替代成果自动交付，避免两条通知。

## 后果与边界

标题与正文通用，不与资料整理绑定。密钥不进入模型、参数、审计或回执；不确定外发不自动重试，SENT 不代表手机已读。超长内容须先摘要，同一回合只有一条通知。原 V1–V59 checksum、设置、归属、部署模式和固件保持。
