# ADR 0066：通知语音反馈先确认最近播报对象

- 状态：ACCEPTED
- 日期：2026-09-14

## 背景

原语音反馈从过去 24 小时的可互动外部通知中寻找支持当前动作的一条，会跳过更新的普通提醒、已回应通知或不支持该动作的消息。用户说“知道了”时，最近听到的对象可能与被修改的对象不同。

## 决策

语音反馈先查询当前设备、当前角色最近三十分钟内全部来源的成功播报，且必须晚于持久话题边界、不晚于当前时间。包括周期提醒已播出但再次进入待播状态的上次结果。只检查最新对象；相同完成时间的多个候选不靠 ID 猜顺序。

仅当最新对象为已播放、支持相应回执且没有终态回执的外部通知时，才为该 ID 提案。不得跳过更新对象寻找较旧通知。没有可执行对象时，“知道了”只自然回应，不修改数据；“完成了”或推迟通知需要用户明确对象。外部通知显式按 ID 的管理/来源接口仍保留 24 小时窗口，不改变来源授权动作。

## 证据和后续

定向 35/35 通过，含隔离 PostgreSQL 查询：多来源排序、周期提醒、其他设备/角色、未来/陈旧/失败记录和边界过滤；单测覆盖更新普通提醒、同时间歧义、不支持动作不回退及当前角色提案。

日志：`server/target/recent-response-verification.log`。此前 540/540 完整回归发生在此修改之前，不能替代本次最终全量回归。跨来源普通提醒/工作休息的完整口语回应、提案中外部通知名称以及聚合视图仍在实施清单中，本 ADR 不声称已完成全部统一回应工作。
