# 0070：混合输入与明确许可的桌面陪伴

- 状态：ACCEPTED
- 日期：2026-10-01
- 工作流：全局
- 相关提交：`69a98cd`（实现基准；本任务工作树验证另记）
- 关联：[完整交付](../companion-interaction-delivery.md)、[0049](0049-local-vad-gated-live-voice-upload.md)、[0050](0050-low-latency-natural-voice-conversation.md)、[0042](0042-local-first-k151-body-safety.md)

## 背景

用户报告视频/电视人声误唤醒、说完后监听不结束、背景视频进入识别及回应约需 5–10 秒。目标是工作日桌面长时间共处，安静表情和小动作为主，偶尔说话；用户已接受安静唤醒与嘈杂场景按住说话的混合方式，并确认全范围分阶段实施。

## 决策

- 设备空闲时提供本地 `WAKE / PTT` 模式开关，选择 PTT 后暂停 WakeNet 采样与检测，但保留屏幕按住说话；独立 NVS 保存模式，不更改服务端唤醒灵敏度、部署模式或舵机许可。触摸开关不同时启动录音，长按和拖出不切换。
- PTT 松手结束本次采音，整次交互不自动续听；普通监听显示独立提交符号，其他触摸继续取消。空采音不上传，取消后的晚到音频不播放。
- 默认稳健唤醒，仅对新配置生效；已有敏感设置不暗中改写。正常唤醒仍用两窗开始确认，PTT 使用一窗较弱门槛以保留短轻回应。正式讲话最多八秒，等待开口另计；两分钟限制续听和新轮启动，不截断已提交回复。
- 真正重新采样后才报告恢复监听。WakeNet 故障保留可见错误和重试，不悄悄永久退出。显式结束的 SCV2 音频虽不播放，仍接受并推进合法序号。
- 固定动作使用独立、可清除的弱情绪层；录音、处理和播放高于身体事件。头顶空闲短触只表达喜爱，不改角色色、不调用模型、不驱动舵机；长按工作模式和运动触摸急停优先。
- 当前明确“记住”先产生不可召回的候选，再生成两分钟确认。确认绑定管理员、设备、会话、当前伙伴、原始回合、候选 ID、更新时间、标题和内容；后台修改、拒绝、确认、删除或旧替换对象改变均使旧确认失效。重复确认不重复执行。普通明确请求不共用一个泛化记忆标题，避免无关事实互相覆盖。
- 明确请求且有具体时间/主题才提出一次关心；只解析本轮文本，不允许模型选择候选 ID 或创建这种许可。支持明确本地日期/时段/钟点和有界相对时间，含糊表达先澄清，确认时复述本地时间与时区。
- 关心使用独立 `FOLLOW_UP` 来源、一次排期和四小时有效期。设备今日安静、伙伴暂停和主题静默可取消；DND、忙碌、离线或其他伙伴在用时只在有效期内等待。未知播放结果不自动重发，普通 USER 提醒策略不变。只有当前设备/伙伴实际成功播放的关心进入近期语音上下文。
- 持久化 ASR、模型和 TTS 各阶段耗时与固定安全码。设备同回合 `SPEECH_CAPTURED` 至 `PLAYBACK_STARTED` 的 elapsed 差才表示采音结束至首声；缺阶段显示未知，不混用服务端到达时间。

## 原因

背景人声与用户声音都可能是语音。没有手机播放参考时，普通降噪/VAD 不能保证只接收主人。先让用户明确控制采音，比默认增加持续监听、声纹登记或主动频率更符合已确认场景。

官方 [FunASR Flash HTTP 文档](https://help.aliyun.com/zh/model-studio/fun-asr-flash-recorded-speech-recognition-http-api) 使用 `input_audio.data` 和 `output.text / output.sentence.text`，本任务据此修正格式并保留旧响应兼容。已录 PCM 的有序发送无需再人为重放等时等待是本项目输入条件下的实现判断；不据单元测试声称真实云端延迟达标。

[ESP-SR AFE 文档](https://docs.espressif.com/projects/esp-sr/zh_CN/latest/esp32s3/audio_front_end/README.html) 的回声消除需要播放参考。完整 AFE 接入须有内存/模型与现场收益证据；本轮不把增加依赖等同于解决任意视频人声。

## 影响

保持单次 TTS/单 WAV、旧语音 API、旧输入协议、现有角色和提醒业务。新增 V54 诊断列、V55 许可类型及关心来源；新增字段与事件不保存录音、认证载荷或提供商自由错误消息。已有隐私删除和备份范围仍适用。

软件、构建、安装和实体体验分别验收。新制品需要同源完整回归、栈预算、迁移恢复与指纹；安装、部署切换、实际运动和外部推送各自遵守显式授权。代码合入不代表误唤醒样本、识别率或首声延迟已达标。
