# ADR 0065：普通提醒确认固定对象与伙伴范围

- 状态：ACCEPTED
- 日期：2026-09-14

## 背景

评审 M04/M06 要求用户清楚知道正在回应哪个对象。复核发现“下一条提醒”“待确认记忆”语音捷径仍使用默认角色；普通提醒稍后/跳过在确认执行时重新选择下一条，可能因队列变化操作不同对象。

## 决策

语音查询从当前会话解析角色。普通提醒提案在服务端选取当前设备、当前角色的待处理 USER 来源对象，保存其 ID、内容和排期；不采信模型输入的提醒 ID，重述包含具体内容。外部通知和工作提示继续保留自己的操作语义。

确认时按来源锁定原对象，校验设备、角色、排期、内容、待处理状态和未进入合并投递；任何改变均拒绝执行，不重新选另一条。旧版本没有绑定对象的未过期提案确认失败，用户可以重新发起。复用现有提案字段，无数据库迁移。

## 验证与边界

定向 25/25 通过，包含语音查询角色、提案忽略伪造对象、确认不重选队列、不同角色/排期变化/内容变化/取消/旧提案拒绝及 V49→V51 升级。日志：`server/target/scoped-reminder-confirmation.log`。

这是统一回应工作的第一部分；跨来源“刚才那条”“知道了”“稍后”的消歧及近期/待播视图尚待完成，不能据此声明 M04/M06 已全部解决。仍需最终全量回归与部署验证。
