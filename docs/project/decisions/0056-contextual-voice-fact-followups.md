# 0056：日期省略追问继承近期天气与日程工具

- 状态：ACCEPTED
- 日期：2026-09-12
- 工作流：服务端、部署
- 关联：[0054：短时话题承接](0054-bounded-recent-voice-context.md)

## 背景

语音模型已收到近期完整问答，但必需工具路由仅匹配当前用户输入。用户问完天气或日程再说“那明天呢”，会进入不具备工具的短闲聊链，可能把旧数据误用于新的日期。

## 决策

- 当前输入明确命中工具时仍以当前输入为准。
- 只在语音通道、当前输入完整匹配有限日期省略表达时，检查已按设备会话、角色与三十分钟窗口筛选的最近至多四个完整轮次。
- 只继承天气或日程工具。连续日期追问可以向前追溯；遇到其他用户话题、其他工具、非完整问答即停止，不读取助手正文来推断用户意图，不跨越新话题。
- 继续通过已有工具装配、授权、预算和成功调用检查，不增加意图分类模型或外部权限。工具禁用、缺失、失败时保持确定性无法查询回复，不能退回普通模型猜测。
- 日期与内容由已有模型和工具结果解释；提示要求只回答结果实际覆盖的日期，没有数据不等于没有安排。
- 普通短闲聊、确定性时间回复、单次 TTS、主动额度及网页路由保持原行为。无迁移、页面或固件变更。

## 验证与限制

使用模拟模型驱动真实 ReactAgent 工具调用，验证日期追问会执行天气工具；覆盖日程连续追问、工具未授权、Agent 关闭、当前问题优先、游戏转题、助手提及和缺少完整历史。

这是有限表达的路由修复，不是通用意图识别；未识别的复杂省略句不保证继承工具。真实模型的日期理解和措辞仍需实体语音复测，自动化不代表真实模型效果已经验收。
