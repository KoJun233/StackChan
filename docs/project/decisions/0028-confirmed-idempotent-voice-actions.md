# 0028：语音副作用采用结构化提案、确定性确认与幂等执行

- 状态：ACCEPTED
- 日期：2026-07-31
- 工作流：服务端、前端、固件、部署
- 关联：[0020：长期记忆必须经过确认并按会话范围组装](0020-confirmed-scoped-long-term-memory.md)、[0021：提醒与有限主动交互采用确定性规则和设备级控制](0021-limited-proactive-interaction.md)、[0023：对话使用受控 ReactAgent、受信任 Skill 与仅授权 MCP Tool](0023-controlled-react-agent-skills-tools-mcp.md)

## 背景

INT-008 的普通 Agent 只开放只读 Tool，不能创建提醒、修改设置或写入记忆。INT-010 需要让设备语音处理少量明确动作，同时避免模型直接调用业务服务、把普通聊天误判为命令、跨设备确认或重复执行。

## 决策

### 路由与提案

- 只有包含“提醒我”“稍后提醒”“跳过下一次”“音量调到”“安静到”或“记住”等明确表达的设备语音才进入动作提案链；普通聊天继续使用现有 Agent。
- 动作提案链复用 ReactAgent，但只获得一个 `submit_voice_action_proposal` Tool。该 Tool 只接收结构化字段并持久化提案，不得调用提醒、交互设置、记忆或设备业务服务。
- 服务端从认证上下文绑定固定单管理员、设备、会话和来源回合；模型不能提供或覆盖这些字段。模型给出的动作类型、时间、范围、枚举、长度和数值必须再次通过应用与数据库约束。
- 时间不明确、结构不合法、模型未调用 Tool 或供应商失败时不创建提案、不产生业务副作用；回复只能追问或回到普通对话，不能声称操作已完成。

### 确认与执行

- 创建提醒、稍后提醒、跳过下一次提醒、临时免打扰和音量修改必须先返回确定性复述，再由同设备、同会话在两分钟内说出完整确认词执行。
- 完整取消词会取消同范围的待确认提案。过期、跨设备、跨会话和跨管理员确认均拒绝执行。
- 确认以提案主键和行锁保持幂等；只有 `PENDING` 提案能进入执行，重复确认只返回既有终态，不得再次调用业务服务。
- “记住……”是唯一无需二次确认的写入，但只创建 `ASSISTANT_SUGGESTED + PENDING + disabled` 记忆，确认前永不进入模型上下文。
- 首批业务白名单只包含单次/每日/每周提醒、下一条待处理提醒的稍后/跳过、最长 24 小时临时免打扰、0..100 音量和待确认记忆建议。删除、部署、凭据、固件、摄像头、舵机及其他设备控制始终拒绝。

### 查询与审计

- “下一条提醒”和“待确认记忆数量”作为普通 Agent 的只读 Tool，仅从认证设备范围读取；模型不能指定设备 ID。
- 动作审计与业务提案分表。审计只保存提案 ID、动作类型、状态事件、安全失败码、设备/会话/回合标识和时间，不保存用户原句、模型响应、Tool 参数/结果、提醒正文或记忆正文。
- 提案中的业务字段只用于确认复述与执行，不进入诊断、Tool 审计或日志；管理 API 第一版不返回该载荷。

## 发布与兼容

1. V24 先增加提案、审计和临时免打扰字段；默认没有待确认动作，现有聊天、提醒和交互设置行为不变。
2. INT-010 只需替换 server。现有 CoreS3 通过 SCV1 和连续对话跟进完成复述与确认，不新增固件命令或响应格式。
3. 发布前必须验证旧固件普通聊天、提醒播放、音量配置、触摸取消和 `motion_disabled`；未经用户明确授权不替换运行 server 或刷写设备。

## 安全边界

- 生产保持 HTTPS-only，LAN HTTP 只用于显式开发 profile。
- 不记录或返回认证秘密、音频、转写、模型回复、完整 Tool 参数/结果或供应商响应。
- 提案执行失败不得伪造成功；普通 Agent 的既有 Tool 继续保持只读。

## 替代关系

无。本文只为 ADR 0023 增加独立副作用提案层，不扩大普通 Agent、Skill 或 MCP Tool 的写权限。
