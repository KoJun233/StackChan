# 0063：临时主动聊天暂停独立于免打扰

- 状态：ACCEPTED
- 日期：2026-09-13
- 工作流：服务端、前端
- 关联：[功能评审 D03](../feature-review-2026-09-13.md)

## 决策

用户已确定多个伙伴独立。临时暂停的范围问题尚未收到回复，本次按已说明的假设实施：只暂停当前或控制台选定伙伴在这台设备上的主动聊天。普通提醒、任务提醒、外部通知、用户发起聊天及无声表情不受此开关影响；“免打扰”仍是另一项设备能力。

工作简报、休息和观察通知复用了 `PROACTIVE` 来源，但使用既有 `workday:` 主题命名空间；投递检查将其排除，继续由工作日功能控制，不能仅按来源枚举把所有自动消息都视为闲聊。

- V51 保存设备、角色、暂停截止时间和更新时间，设备/角色删除时级联清理。使用参数化 UPSERT 保证重复暂停仅更新同一条范围记录，提前恢复删除该范围记录；过期记录不再阻止生成，无需定时任务解除。
- “今天别主动聊”截至设备时区的下一天起点，正确处理夏令时的 23/25 小时日。“暂停主动聊天 N 分钟”允许 1 至 1440 分钟。“恢复主动聊天”只解除临时暂停，不开启原本关闭的主动聊天，也不重置配额或话题静默。
- 明确指令直接更新可恢复偏好并取消旧待确认操作；否定/引用或普通聊天不触发。暂不使用模型解析含糊时长。
- 生成端在消耗主动配额前检查暂停。投递端在合成前和合成后检查，取消尚未发送的主动消息，恢复后不补播过时消息。已下发播放仍使用既有取消机制，不声称消除网络临界窗口。
- 控制台在当前选定伙伴范围显示设备时间的截止时间，提供暂停今天、一小时和提前恢复；过期状态每三十秒刷新显示，服务端按精确时间判断。
- 新 API 使用显式设备/角色路径：GET 读取、PUT `{minutes:null}` 暂停今天或正整数分钟、DELETE 提前恢复；沿用设置接口的管理员认证。

## 验收

真实 PostgreSQL 验证 V51、重建服务后读回、重复更新、设备与角色隔离、精确到期、提前恢复以及 DST 25 小时日；语音覆盖三类正例、非法分钟、引用负例和普通提醒设置不变。生成测试验证暂停不消耗配额，投递测试覆盖无主题问候及合成期间暂停。HTTP 和前端 API 覆盖同一显式范围及输入校验；执行服务端、控制台回归和构建。正式用户使用和实体语音验收另行记录。
