# 0006：聊天重试按 clientMessageId 对账并保持幂等

- 状态：ACCEPTED
- 日期：2026-07-19
- 工作流：服务端、前端
- 相关提交：`99ab4cd`

## 背景

SSE 在终态到达前断开时，浏览器无法确认服务端是否已保存消息或开始生成；重新生成可能重复保存用户消息并再次调用模型。

## 决策

不明确的传输重试复用 `clientMessageId`。服务端已确认安全错误时，重新生成使用新的 ID。重复请求绝不调用模型；取消仍保持 `INTERRUPTED`。

## 原因

服务端可按同一会话中的 `clientMessageId` 返回既有消息状态，前端据此对账或重放，避免把不确定传输错误误判为可重新调用模型。

## 影响

后续聊天客户端和服务端必须保留该请求身份与重放语义。未来 Agent 不得改变本 ADR 确定的幂等与取消语义或暴露存储的秘密；如需变更，必须有用户批准的新 superseding ADR。
