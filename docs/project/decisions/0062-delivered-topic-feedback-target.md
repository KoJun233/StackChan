# 0062：主动话题反馈对齐近期实际播放内容

- 状态：ACCEPTED
- 日期：2026-09-13
- 工作流：服务端
- 关联：[功能评审 D03](../feature-review-2026-09-13.md)、[0061](0061-role-scoped-proactive-topic-feedback.md)

## 决策

主题冷却记录在生成提醒时建立，不能证明用户听到了该话题。语音“别再提这个”改为复用已播放上下文查询：同一设备、同一角色、最近三十分钟、成功播放、非未来，且播放完成时间晚于当前会话显式换题边界。

只使用最新一条成功播放消息的主题键。若最新消息没有主题、已过期或不存在对应主题记录，不向更早的兴趣话题回退，不修改其他偏好；回复明确说明未修改。旧聊天与长期记忆不用于猜测反馈目标。

投递器在处理队列时以及语音合成完成后检查持久话题静默状态，同主题未发送主动提醒标记取消。这个检查只针对有主题键的主动消息，不影响普通提醒、任务或外部通知。已下发给设备的播放不能通过此数据库检查撤回，仍使用既有触摸/语音取消链路；不宣称消除了网络下发临界时刻的全部并发窗口。

无新数据库迁移；主题记录仍用于七日冷却，反馈语义改为成功播放证据。临时主动暂停和命名话题反馈尚未纳入本决策。

## 验收

真实 PostgreSQL 验证较新的排队主题不能取代已播放主题、换题边界不能跨越、无主题新问候不能回退旧主题；现有查询测试覆盖失败、取消、过期、未来及其他设备/角色。投递测试覆盖入队后静默、合成中静默和普通提醒不受影响。实际口语和设备取消体验仍需实体验证。
