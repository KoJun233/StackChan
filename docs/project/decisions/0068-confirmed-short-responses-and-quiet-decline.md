# ADR 0068：简短回应固定对象与轻量拒绝

- 状态：ACCEPTED
- 日期：2026-09-14

## 决策

“稍后”“知道了”“完成了”先查看当前设备、当前伙伴、当前话题边界内最近三十分钟成功播放的所有来源。同时间歧义、过期对象、更新的其他来源均不回退旧对象。

普通提醒的“稍后”先重述内容，确认后新增一次性再提醒，保留原周期和待办状态；确认时重新校验原内容、归属和实际播放时间。同一确认重试不重复创建。“完成了”不把提醒自动转成待办完成，要求明确待办标题。

工作休息提案保存当前休息提示的状态时间，确认不得作用于下一次休息提示；近期反馈还校验听到的时间不早于当前提示。保留原有十分钟稍后语义，不额外提供任意工作节奏。外部通知提案由服务端取真实内容，重述前四十八码点并说明“回报完成”不等于执行外部任务。模型不能自行填入业务对象引用。

“先不聊”“不聊这个”“现在忙”等明确拒绝固定简短收尾，关闭本次话题并取消旧确认，不调用模型或提取记忆。否定、引用及讨论这些措辞不按控制命令处理。它不改变全天主动开关；“今天安静点”另归入当前设备/伙伴的当天主动暂停，普通和工作提醒照常。服务端话题关闭不等于新增固件关麦命令，固件结束聊天行为保持既有实现。

## 验证

服务端回归 554/554、V1..V51 空库迁移及 V49→V51 升级、JAR 打包通过，日志 `server/target/short-response-regression.log`。排除八个既有 Windows loopback 环境受限测试类，不宣称全测试套件通过。覆盖对象变化、重复确认、来源与角色隔离、过期通知、旧休息提案和单次拒绝。实际识别率、口语覆盖和听感留给用户真机测试。
