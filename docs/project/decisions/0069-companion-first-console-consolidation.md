# ADR 0069：陪伴优先的控制台收敛

- 状态：ACCEPTED
- 日期：2026-09-14

## 决策

保留现有数据模型与授权边界，收敛使用入口。“个人事务”只放普通提醒与个人待办；外部通知移入默认折叠的“高级扩展”。能力页默认展示日常事实查询，自定义 Skill 再次折叠，运行策略、MCP 与审计保留高级入口。原 `/settings/agent`、`/notifications` 链接和命名路由保持兼容，通知详情保活约束不变。

主动陪伴设置优先展示打扰策略。工作模式保持可选；工程观察明确不衡量陪伴价值。两个可选角色草稿分别体现温和倾听与好奇聊天，只填充新角色草稿，不覆盖现有伙伴；追问风格不代表主动打扰频率，未指定音色继续回退全局配置。

记忆页面说明伙伴归属、确认替换及遗忘范围：停用/删除停止长期记忆加载，但原聊天可能仍在近期上下文中，已有备份继续按保留周期轮转；清空全部明确影响所有伙伴，不受筛选限制。

冻结通用 Skill 市场、扩展通知平台、资讯扩源、新动画格式和复杂任务系统。原生表情、PNG/EAF、固件升级、配网迁移、诊断、备份及安全能力保持兼容，不因低频删除。身体动作继续禁用，素材与实体能力不冒充已验收。

## 验证

控制台 33 文件 107/107、类型检查、相关 ESLint/Stylelint 通过，菜单分组、折叠标识、旧深链接和数据竞态有自动化覆盖。正式 Dockerfile 使用固定 Node 24.15.0、pnpm 11.13.1 构建新页面与服务端成功。真实页面与实体体验结果另记部署状态。
