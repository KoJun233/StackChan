# 0071：设备双眼、固定内容确认与默认关闭的本地跟随

- 状态：ACCEPTED
- 日期：2026-10-03
- 工作流：全局
- 相关提交：`effa511`（实现基准；DEVICE-008 最终来源由候选 manifest 固定）

## 背景

用户提出舵机卡顿、测试动作未用于实际互动、情绪单一、屏幕模式按钮和冗长语音确认等六项问题，并确认 Q1–Q14 的交互、视觉和权限边界。现有 CoreS3/K151 使用 LVGL 和固定 OTA分区，摄像头与 LTR303 共享电源，普通录音/播放与运动必须互斥。旧软件已安装，不把旧许可与验收自动迁移到本任务。

## 决策

1. 基于已过时间计算五次缓入缓出目标，绝对节拍且迟到时合并过期步骤，统一硬件速度限制；保持反馈/超时/本地停止。非中心跟随姿态切入模板必须先证明整个轨迹符合原预算，不能靠中途延长 watchdog。
2. 使用本项目独立 LVGL 双眼渲染，借鉴 RoboEyes 的简洁眼形、眨眼、眼睑、视线与平滑过渡，不导入其 Arduino/Adafruit 绘图实现或 GPL源码。原生情绪支持十二种，绑定回合；TTS首播开始寿命，讲话不盖住情绪，旧/取消/结束回合不复活。高优先级系统状态覆盖情绪。
3. 空闲左滑→PTT、右滑→WAKE、上滑→菜单；保留按住600 ms说话和录音提交。取消旧空闲按钮，用短暂眨眼/文字和不可点击状态符号提示。模态或屏保拥有整个触摸周期，忙碌触摸优先停止；摸头在已许可条件下可轻点头。
4. 新设备协商 UI v1；卡片展示固定动作、内容、时间/时区、伙伴，执行只提交固定 proposal_id 与 CONFIRM/CANCEL。确认卡片排除过期、内容变化、伙伴切换、会话变化和重复执行。实际渲染后的 SHOWN 回执才允许简短提示“请确认屏幕上的内容”；回执失败/旧设备仍完整语音复述。停声按钮只停提示音。
5. V56 保存任务/提醒快照及伙伴 consent_epoch；换伙伴后即使切回也不复活旧同意。升级前旧伙伴周期提案退役。设置只接受单字段窄命令，回复 SAVED 才称已保存；状态变化提交事务后通知能力连接，旧缓存不能再次覆盖硬件值。
6. 控制中心支持输入模式、音量、亮度/夜间、今天安静、工作/休息、伙伴、连接/电量和停止。输入模式本地 NVS持久；亮度是当前启动的覆盖，相机重启关闭。菜单不提供 armed、校准、OTA或凭据入口。
7. 图像只存在本地工作缓冲，不做身份识别/保存/上传。菜单打开 GC0308 QVGA RGB565BE，默认关闭；只在空闲、状态新鲜且允许时运行。模型固定 MSR/MNP S8，先最大脸再位置连续，短失联保持，持续丢失回中。眼神连续，头部由独立舵机许可控制且至少隔六秒；保持 yaw±12°与当前校准 pitch0..6°限制。
8. 检测、网络、门禁分任务，失效代数排除在途旧采集；停流失败保留 DMA缓冲直到真正释放，不关闭共享电源。PSRAM网络任务通过内部 RAM ui_flash 任务读 NVS/保存模式，避免 Flash缓存关闭时访问外部栈。
9. 原分区不变，完整中文字库由 OFL源离线生成。按实际模型读取算子和量化类型，用 ESP-DL 公共 compile requirements API 保留真实依赖与36个S8内核；官方 Kconfig仅启用 RGB565→RGB888 转换，固件使用 -Os。选定栈调用边界 noinline以保持预算可复验，GCC优化克隆按最大帧汇总，不降低第三方余量门槛。

## 原因

确定手势与固定卡片减少额外语音往返；明确事实源、伙伴周期和回执避免用户点击陈旧或未实际显示的内容。有限跟随保留唤醒空档，采集与运动可独立关闭。编译裁剪保留原模型、完整中文和原分区，避免安装时强制迁移存储布局。

## 影响

软件回归/模拟/真实LVGL绘制可先完成；摄像头运算、内存峰值、屏幕时序及供电/运动感受必须等许可后真机测量。3 Hz仅预算，静态栈只覆盖选定本地路径。应用接近3 MiB上界，后续功能必须继续验证容量。数据库升级与应用回退须分开考虑；旧设备语音确认仍兼容。
