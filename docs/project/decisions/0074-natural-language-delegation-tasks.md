# ADR0074：自然语言通用持续任务

- 状态：ACCEPTED
- 日期：2026-10-10
- 关联：[COMPANION-009](../recurring-research-delivery.md)

## 背景

用户实测发现 V58 的任务结构和执行流程仍局限 RSS 资料整理，无法自然表达生活与项目事务。用户明确确认任务描述为主，由 AI 理解具体操作；完整条件直接接下，缺关键条件追问。闹钟和电脑开机只是示例，本轮不实现这些新能力。

## 决策

保留「持续委托」路由、管理员权限和 Bark，把创建输入收敛为设备、伙伴、描述与启用。模型规划时间、理解、交付方式和当前工具范围，服务端校验后保存。资料来源不再必填，旧字段只作兼容偏好。ONCE/DAILY/WEEKLY/INTERVAL 共用持久触发与幂等机制。

所有新旧任务通过通用 ReactAgent 执行，不继承聊天回退成功。执行时仅开放保存范围与当前授权的交集，每步验证任务状态及修订。结果包含通用正文、实际步骤和证据。现实查询与外部动作必须完成对应工具调用；缺能力或证据记 BLOCKED。纯文本创作单独标记生成内容。

公开网页/feed 读取作为 Tool，来源引用取实际结果。V59 追加结构且保留旧数据和迁移 checksum，DELEGATION 审计关联 run/attempt。任务创建可从明确的文字或语音委托进入，服务端固定归属；控制台承担完整管理。

## 后果与边界

新能力通过已有授权 Tool 接入，无需增加资料任务类别和表单。模型解释及语义结果需要真实使用验收；没有任意设备控制或通用搜索引擎。工具名保存范围不等同于永久固定外部服务语义，工具/schema 变化仍受当前管理员配置约束。正在发生的外部动作不可撤回；暂停阻止后续操作和旧结果交付。

本 ADR 替代 [ADR0073](0073-recurring-research-and-bark-delivery.md) 中固定资料输入、固定研究执行和每天唯一运行槽的限制；其密钥、HTTPS、Bark 投递与迁移安全约束继续有效。
