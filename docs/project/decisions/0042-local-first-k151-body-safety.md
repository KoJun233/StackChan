# 0042：K151 身体动作由固件本地安全状态机最终裁决

- 状态：ACCEPTED
- 日期：2026-08-29
- 工作流：固件、服务端、前端
- 相关提交：待 BODY-001 任务提交

## 背景

K151 具备两个反馈舵机、顶部触摸及 LTR-553 接近/环境光传感器。远程服务可以失联、重复发送命令或晚于语音和升级状态，因此服务端校验不能替代设备本地的运动安全边界。原始距离、照度和舵机反馈也不需要离开设备。

## 决策

- 设备每次启动均为 `motion_disabled`，不会因 NVS 中存在校准值而自动恢复动作。
- 中位校准只在管理员显式操作后短暂给舵机供电，先关闭扭矩，再读取并保存两个反馈位置；校准本身不发送目标位置。
- 管理员显式启用时再次执行无动作反馈探测。只有 K151 动作硬件、反馈、有效校准都存在时才进入 `motion_armed`。
- 协议只允许 `WAKE`、`LOOK_USER`、`NOD_SMALL`、`THINK`、`DROWSY`。每个模板的角度、速度、时长、回中和看门狗均编译在固件内；任意角度、速度、循环和 URL 一律不是协议字段。
- 垂直角限制为 10°..80°，水平限制为中心左右 20°；目标原始位置还必须位于舵机 0..1000 硬范围。
- 录音/活动语音回合、TTS、升级、离线、设备错误、并发动作、超时、顶部触摸或反馈偏差会拒绝或停止动作。安全失败会关闭扭矩和供电，并回到 `motion_disabled`。
- 服务端可保存能力位、在场布尔值、环境光分档、动作状态、最后失败码和累计计数；不得接收或保存原始传感器、舵机位置或触摸通道流。
- K151 缺失或任一子设备探测失败时，其能力位为 `false`，显示、语音、日历和天气继续运行。

## 原因

动作模板和最后拒绝权都留在设备端，可以使断网、命令重放、服务端缺陷和音频并发都无法绕过机械边界。短暂、无目标位置的反馈探测避免重启后自动动作，并允许持久校准继续使用。只上传分档和布尔诊断满足工作模式判断，同时避免形成环境或运动原始数据流。

## 影响

- BODY-001 服务端先于固件发布时，旧固件省略能力位即解释为不支持，页面禁用所有动作按钮。
- 首次实体启用必须按独立 runbook 逐步完成，并分别获得固件安装和动作测试授权。
- 任何反馈异常后都必须重新校准并由管理员再次启用；服务端不得自动重发启用命令。
- 摄像头、NFC、红外、RGB 动画、任意运动和模型运动权限不随本决策开放。
