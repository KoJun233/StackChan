# 0016：唤醒词仅从 ESP-SR 内置模型目录选择并安全 OTA

- 状态：ACCEPTED
- 日期：2026-07-26
- 工作流：服务端、前端、固件、部署

## 背景

ESP-SR 的 WakeNet 不能把任意运行时文本直接当作模型。此前的在线生成与模型包上传方案需要额外生成服务、文件契约和运维入口，超出了当前产品需要。项目已经锁定 ESP-SR 2.4.6，组件中自带一组可直接使用的 WakeNet9/WakeNet9l 模型；CoreS3 当前镜像也已链接对应运行接口并完成三模型槽引导。

## 决策

- 管理页面不再接受任意短语或模型文件，只显示服务端固定白名单中的 ESP-SR 2.4.6 内置唤醒词。
- 首批目录包含 `Hi, Stack Chan`、`小峰小峰`、`小爱同学`、`你好小智`、`你好星宝`、`Hi, 乐鑫`、`Hi, ESP`、`Alexa`、`Jarvis`、`Computer`、`Hey Gigi`、`Bonjour ESP` 和 `こんにちは ESP`。
- 服务端从镜像内随附的 `server/wakenet-models` 读取项目锁定版本的原样官方文件，现场生成 `srmodels.bin`；该目录记录上游提交、组件哈希和许可证。请求只能提交白名单模型名，不能提交路径、URL、文件或自定义短语。
- 每个 OTA 包包含目标模型和 `wn9l_histackchan_tts3` 出厂回退模型；当目标本身是出厂模型时只打包该模型。服务端仍校验结构、连续文件区、SHA-256 和 1 MiB 上限。
- 继续复用 0015 已实现的设备鉴权下载、非活动槽写入、重启健康确认、NVS 幂等补报和自动回退；取消在线生成器、上传接口及其页面入口。
- V12 作为已部署过的迁移历史保留，V13 终止遗留活动任务并删除临时 `source` 字段，避免修改已应用迁移的校验和。
- 选择唤醒词会创建 `READY` 任务并在设备在线时触发 OTA 与重启。页面加载、查看目录或部署本功能不会自动切换设备模型。

## 原因

固定目录消除了第三方数据提交、任意文件上传和不可用生成器三类依赖，同时保留用户无需刷固件即可切换唤醒词的体验。服务端只打包仓库锁定的官方模型文件，输入面显著缩小；原有三槽回退仍负责处理损坏、掉电或模型启动失败。

## 影响

- 用户不能输入任意唤醒短语，也不能上传本地训练模型。
- 新增词必须先进入项目锁定的 ESP-SR 组件并经兼容性、容量和真机验证，再加入服务端白名单。
- 当前 CoreS3 的 `0398073` 镜像已经包含 WakeNet9/WakeNet9l 运行接口和三槽逻辑，本次不需要再次刷写。
- 首次实际选择某个新词仍会使机器人下载模型并重启；这由管理员在页面主动触发。

## 替代关系

替代 [0015](0015-runtime-wake-model-generation-and-ota.md) 中的在线生成与本地上传入口；保留其设备三槽 OTA、安全下载和自动回退设计。
