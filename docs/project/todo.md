## 固定产品与安全边界

- 机器人服务于一位长期用户；近期不引入多用户权限体系。
- 只有已确认且启用的记忆可进入上下文，角色切换不得扩大记忆范围。
- Agent Tool 和外部通知令牌均采用最小权限；模型不能提供或覆盖设备、角色、会话和授权范围。
- 外部通知不调用 LLM 改写正文，不允许绕过免打扰，不接受任意回调 URL。
- 不开放语音删除、部署、凭据、固件、摄像头或舵机操作，`motion_disabled` 保持不变。
- 生产保持 HTTPS-only；LAN 与 production Compose 不可组合。

- 当前角色的设备语音会话保持持久，但交给模型的话题上下文只保留最近三十分钟内至多四个完整用户/助手轮次。
