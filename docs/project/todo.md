## 固定产品与安全边界

- 机器人服务于一位长期用户；近期不引入多用户权限体系。
- 只有已确认且启用的记忆可进入上下文，角色切换不得扩大记忆范围。
- Agent Tool 和外部通知令牌均采用最小权限；模型不能提供或覆盖设备、角色、会话和授权范围。
- 外部通知不调用 LLM 改写正文，不允许绕过免打扰，不接受任意回调 URL。
- 不开放语音删除、部署、凭据、固件、摄像头或舵机操作，`motion_disabled` 保持不变。
- 生产保持 HTTPS-only；LAN 与 production Compose 不可组合。

## `EVT-001`：外部通知平台

### 交付范围

- 复用提醒调度、TTS、同源音频和设备 ACK；新增 `EXTERNAL` 来源、过期终态、集成归属、幂等键和过期时间。
- 外部通知默认 24 小时过期，离线可靠排队，尊重免打扰和忙碌；每台设备同时最多一个已派发播报。
- 管理员创建绑定单设备的通知集成；令牌只显示一次、仅保存哈希，支持到期、轮换、禁用和撤销。
- 提供带 `Idempotency-Key` 的 REST 创建/查询接口，以及只包含 `push_notification`、`get_notification_status` 的 Streamable HTTP MCP。
- 新增外部通知管理页面和安全健康计数；正文、令牌和认证载荷不进入健康接口或日志。

### 验收边界

- 覆盖撤销/过期令牌、越权、限流、队列上限、幂等冲突、免打扰、忙碌、离线、过期、重启恢复、设备单飞、TTS 失败和 ACK 重放。
- REST 与 MCP 复用同一业务服务；管理员会话、CSRF、现有提醒 CRUD 和 Agent MCP Client 不受影响。
- LAN development 可使用受信任内网 HTTP；公网 production 只允许 HTTPS。
- 实体设备验证在线播报、免打扰延期和离线重连播报；本任务不需要刷写固件。

## `ROLE-001`：角色容器与严格隔离

### 交付范围

- 新增角色和每设备活动角色。角色保存名称、结构化语气/长度/主动程度、受限背景说明、边界、禁忌和归档状态。
- 现有单例人设、会话、记忆、提醒、主动主题和通知集成迁移到默认 `StackChan` 角色。
- 网页会话永久绑定角色；设备语音会话按 `deviceId + roleId` 隔离。模型不能提供或覆盖角色范围。
- 管理页和明确语音动作均可切换角色；语音切换复用两分钟、同设备/同会话、确认后幂等执行的提案机制。
- 默认角色不可归档。归档角色会切回默认角色、取消未来提醒并停用通知集成；历史数据保留只读、可筛选和导出。
- 设备凭据、网络、OTA、音量、免打扰、模型密钥、Skill/MCP、首版音色和表情继续共享。

### 验收边界

- 覆盖默认迁移、网页/设备会话隔离、记忆、主动问候、提醒、Agent Tool、语音切换、归档和个人数据导出。
- 两个角色分别记住不同事实，切换后历史与记忆不串用。
- 本任务不改固件、不切换音色或表情。
