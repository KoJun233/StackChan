# WORK-006：今日个人待办进度查询

- 文档状态：COMPLETED
- 日期：2026-08-31
- 实现基准：`221711f`
- 工作流：服务端、部署

## 目标

让用户可以主动询问机器人“今天完成了什么”或“任务进度怎么样”，并得到当前设备、当前活动角色范围内的今日完成项与现有未完成待办。功能扩展既有 `current_personal_tasks` 只读 Tool，不新增主动播报、模型写权限或第二套待办数据。

## 固定边界

- “今天”按当前设备工作日设置中的 IANA 时区计算，使用本地自然日 `[00:00, 次日 00:00)`；不依赖服务端宿主机时区。
- 只查询当前认证设备和当前活动角色，不能由模型提供或覆盖设备、角色和时区。
- 现有未完成待办继续最多返回二十项，并保留兼容的 `tasks`、`count` 字段。
- 今日完成项最多返回十项，按完成时间倒序确定性选择；提供给模型的完成项只包含标题。
- 备注、精确完成时间、完成项 ID、设备 ID 和角色 ID 不进入 Tool 结果。
- 用户询问待办、今日完成情况或任务进度时必须成功调用该 Tool；Tool 未授权或失败时禁止依据历史对话猜测。

## 与既有能力的关系

- 不修改待办 CRUD、截止提醒、确认式语音新增/完成和 WORK-005 首次简报规则。
- 不新增数据库迁移、管理页面、主动通知、工作日聚合指标、固件命令或身体动作。
- 不改变 2026-08-30 至 2026-09-12 的十四天观察窗口、门槛和每日主动播报计数。

## 验证与验收

- 单元测试覆盖设备时区边界、当前设备/角色范围、十项上限、最小字段和 Agent 强制路由。
- PostgreSQL 持久化测试执行真实 JPQL，确认本地日边界外及其他范围的数据不会进入结果。
- 自动化回归后只替换 LAN server；运行库继续保持 V45，CoreS3 和 `motion_disabled` 不变。
- 人工验收：在当前角色至少完成一项待办后，询问机器人“我今天完成了什么”或“今天任务进度怎么样”，确认回答同时区分今日完成项与剩余待办，且不复述备注或精确完成时间。
