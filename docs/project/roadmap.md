# 产品路线图

本路线图记录产品优先级，而不是频繁变化的单项实施任务状态。

1. **P0 — COMPLETED：**受控 ReactAgent、Skill、只读 Tool、显式授权 MCP，以及个人数据生命周期、自动备份和隔离恢复演练均已合入并验收。
2. **P1 CURRENT — ACTIVE：**交付回答后的短暂连续对话。
3. **P1 NEXT：**依次交付安全语音操作、长期记忆 2.0 和有边界的个性化主动关心。
4. **P2：**建设固件应用 OTA、健康中心和可选连接器；宠物形象 AI 生成等待隐私与基准图确认。

任务拆分、依赖、第一条精确操作和验收条件见[下一阶段可执行任务清单](todo.md)。

## 已完成的基础能力

- 管理员控制台
- LLM 配置
- 流式文本聊天
- 聊天重试幂等性
- 设备配对/会话安全
- LAN 开发模式

- 可控人设、确认后生效的长期记忆、周期提醒和有限主动问候
- 动态机械眼、八状态宠物表情资源包与 CoreS3 实机验证
