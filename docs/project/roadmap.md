## 产品边界

- 近期保持单管理员、单长期用户；角色不是多用户权限账户。
- 设备凭据、网络、OTA、音量、免打扰、模型密钥和首版 Skill/MCP 继续共享。
- 本地唤醒和本地 VAD 保持不变，不建设常开云端录音。
- 模型不直接获得数据库、文件系统、凭据或任意副作用权限。
- LAN HTTP 仅用于受信任开发环境；公网生产必须 HTTPS-only。
- 摄像头、NFC、红外、多人识别、插件市场和公网明文接口不进入当前路线；舵机只允许本地校准后的固件内置模板。

## 延后事项

- 多资源包同时常驻、GIF、任意视频和动态主题编辑器不进入 V2；V1 PNG 与 V2 EAF 当前共享互斥 A/B 槽。
- 语音插话要先验证硬件回声消除能力；先交付可取消的有序分段 TTS。
- 宠物形象 AI 生成继续等待素材隐私、删除策略和基准图确认，现有资源包 V1 格式不变。
- 开源安装、多硬件兼容、日历写入、随机主动闲聊、iOS App、Home Assistant、舞蹈和模型运动控制延后到六至八周私用结果之后。
