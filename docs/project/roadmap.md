# 产品路线图

本路线图记录产品优先级，而不是频繁变化的单项实施任务状态。

1. **P0 COMPLETED：**跨会话文档系统、无历史会话恢复演练和最终全分支审查已完成。
2. **P1 CURRENT — ACTIVE：**迭代机器人与用户的持续交互，包括可控人设、长期记忆、主动提醒和可解释的状态反馈。
3. **P2：**在选定目标服务器和 HTTPS 入口后，进行服务端部署加固和生产可观测性建设。
