## 实施与验收边界

1. 配置点击重启仍需现场定位：收集有界脱敏panic与复位原因，执行真实生产UI路径的隔离反复点击/保存状态回归；补项目/第三方调用预算与现场高水位，复现后修复。效率改动可以独立验证，但不能因此宣布重启根因。
2. 改为只创建当前图标页或配置页，保留对象、差量更新状态，避免每次dirty全删除/重建。请求与页面独立，切页不能让旧结果覆盖新的设置或复活旧卡片；不把HTTP/NVS放进触摸回调或PSRAM Flash栈。
3. 修改WAKE录音触摸归属，短触提交、下滑取消，删除旧热区；未完成手势不能先取消/提交。PTT松手、忙碌触摸停止和急停优先级保持。
4. 使用原生图形与更清晰的字体，比较固定菜单灰度小字集/压缩方案，保留完整内容覆盖、缺字时禁止确认。校验字形索引、原应用槽容量、RGB565实际格式的31情绪/菜单/配置/卡片场景，不盲目扩大DMA内部缓冲或提高SPI时钟。
5. 优化脏区、调度与音频并发，先测再调整20帧播放上限。统计显示完成、帧间隔p50/p95/p99、长帧/触摸到反馈、内部可用连续内存及音频错误；不能拿目标值或某条actual_fps证明稳定60。非动态静止页无需持续整屏重绘。
6. 宿主、容量与双固件编译、四种实际栈报告及相关回归通过后制作来源/摘要固定候选；实现/验证/状态/交接保持同一中文任务提交，不外推。真实屏幕点击/语音并发和帧率仍需候选安装后的现场核验，不继承714c030安装成绩。

相机/实体运动继续关闭，不改校准、Wi-Fi、身份、生产HTTPS边界、现行服务/V56或分区。用户上次USB许可针对714c030恢复在线，不能代替此轮新候选安装许可；先完成实现与具体制品再处理安装许可。
