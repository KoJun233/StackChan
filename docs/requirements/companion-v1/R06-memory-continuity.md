## 1. 完成到什么程度

用户今天说明“我正在做桌面布置方案”，机器人提出可核对的记忆/待续候选，用户确认后才保存为可用长期背景。
第二天用户聊到这个项目时，机器人能沿真实已确认事实接一句，查询项目进度时读真实目标/成果状态。
用户纠正预算或偏好，本轮先按新信息回答；长期改动先出候选、展示旧新差异、确认后原子替代。
“先不聊”暂停至设备当地次日，“别再提”持续停止，明确恢复后才继续。
删除来源会清理复制进展，删除记忆后旧确认、检索缓存和主动候选均不能将它复活。
未知结果就承认未知；不能把自己的总结说成共同经历，也不能把保存许可变成主动开口许可。

## 3. 范围与排除

纳入：已确认记忆召回、限定同义匹配、当前明确表达优先、纠正候选、来源可解释、V57 跨天接续。
纳入：R03 当前目标的只读上下文快照；目标事实继续由目标表负责，不复制成个人事实。
纳入：删除、暂停、拒绝、休眠、角色变化与并发保护。
排除：全量聊天永久摘要、关系图、亲密度、情绪/心理推断、未经同意的私人资料摄取。
排除：向量数据库或 embedding 默认上生产；有界语义检索仅在现有方法实测不足时独立试验。
排除：把外部网页、模型结论、工具成果、已读/采用事件自动变成已确认个人记忆。

## 4. 功能规则

### 来源、许可与确认

- FR06-01：维持短期对话、确认长期记忆、待续进展、目标状态四种事实来源；各自保留来源、时间和原角色。
- FR06-02：现有旧确认记忆升级后仍是原普通记忆；不得自动获得待续、主动提起或进展存储许可。
- FR06-03：allowProactiveMention=false 保持默认；用户允许“记住”或“以后相关时接着聊”不等于允许主动开口。
- FR06-04：未确认建议不可召回；拒绝建议不可换标题再次询问；异步抽取不发送主动语音或自动打开设备卡片。
- FR06-05：确认绑定管理员、deviceId、roleId、conversationId、sourceTurnId、候选 ID、更新时间、标题和正文；有效期保持 120 秒。
- FR06-06：角色切换、正文修改、旧对象改变、拒绝、删除、到期使旧确认失效；重复同一确认只返回原结果，不重复替代。
- FR06-07：待续候选保留 V57 标题最多 40 字符、正文最多 80 字符及场景过滤；不保存情绪、敏感、人际倾诉推断。
- FR06-08：整台设备每天最多一条待续生成和一条首次展示，跨角色/进程原子控制；删除、取消、重启、时区修改不能重置当日消费。
- FR06-09：已有拒绝/停止的主题不会被新的模型建议覆盖；同主题候选与已确认内容的去重依据业务主题和来源，不靠标题时间戳。

### 召回与当前目标承接

- FR06-10：当前明确表达最高优先；其次本次明确目标与其当前修订、最近完整回合、相关已确认记忆、获准待续背景。
- FR06-11：普通记忆召回继续有界，最多 8 条；查询规范化最多 500 Unicode 码点，同义展开后的有效检索词项最多 64 个。
- FR06-12：增强同义词须可枚举、可测试、只限本期目标与日常场景；“方案”不得泛化命中所有计划，“那个”不得跨会话选对象。
- FR06-13：待续一轮至多选一个相关主题；同分或多对象歧义时不自动选择，询问一次具体对象。
- FR06-14：只有 CONFIRMED、enabled、未被替代、正确 device/role 范围内的记忆可参与正文；GLOBAL 仍是角色内全局，不能跨伙伴。
- FR06-15：检索异常返回无记忆上下文，普通聊天仍可继续；不得用高重要性但无关的旧记忆当后备内容。
- FR06-16：目标上下文只读取用户明确指定或当前会话唯一绑定目标；最多一个目标摘要，不按全设备最新目标强行接续。
- FR06-17：目标上下文使用实时 revision/status/artifact 引用；RUNNING 不说明用户已经完成工作，SENT 不说明用户看过或采用。
- FR06-18：无目标或无相关记忆时承认背景不足；不能把未查询的目标进度、网站内容或模型猜测写成既有经历。
- FR06-19：短指代仅沿最近 30 分钟、同会话、当前话题边界内最近已讨论的具体主题；换话题/结束使旧短指代失效。
- FR06-20：相关跨天接续保留至少隔设备当地日期的既有 V57 规则；回复先处理当前问题，再最多自然接一句，不每轮追问。

### 纠正、替代与删除

- FR06-21：用户“不是 500，是 800”的本轮纠正立即影响当前回答；没有明确长期修改意图时不改记忆与目标。
- FR06-22：明确纠正长期记忆时生成 replacement PENDING 候选，展示旧新内容；确认之前旧已确认事实不被静默覆盖。
- FR06-23：候选确认与旧事实标记 superseded 必须同一事务；旧对象在候选之后已更新、停用或替代时返回冲突，重读并重新确认。
- FR06-24：旧事实被替代后退出召回、主动候选和待续组装；删除新事实不会自动恢复旧事实；恢复需用户另行选择。
- FR06-25：同一管理员手动维护记忆的已有入口保留；涉及纠正替代/待续许可的操作显示明确保存对象与范围，不以普通文本编辑扩大许可。
- FR06-26：删除单条记忆物理删除原对象并清理引用、使用记录、确认候选/缓存、普通主动关联；不保留可重新召回正文的隐蔽副本。
- FR06-27：删除来源会话任一消息，保守清除该会话复制的待续进展；已单独确认的原事实仍可在记忆页单独管理，页面必须解释这一区别。
- FR06-28：进展写入与来源删除共用会话锁；删除先成功后晚到的完成/异步抽取不能重建来源或复制进展。
- FR06-29：候选、记忆正文和目标快照组装后在输出/写入前重验来源有效性；删除响应成功后不得新生成或再次调度已删除来源内容。
- FR06-30：已经在删除前发到设备的音频不能承诺物理撤回；停止新发送并本地尽力取消，诊断保留真实时序而非虚报完全撤回。

### 待续状态与并发

- FR06-31：保留既有 NONE、PENDING、ACTIVE、PAUSED、STOPPED、DORMANT 等待续语义，不与 R03 目标状态合并。
- FR06-32：“先不聊”只暂停唯一当前主题至设备当地次日；“别再提”持续 STOPPED；对象不明先澄清，不能暂停全部记忆。
- FR06-33：STOPPED 只在明确主题恢复时转 ACTIVE；午夜、开启主动开关、角色再次切回来均不自动恢复。
- FR06-34：连续 14 天没有用户进展进入 DORMANT；休眠不删除确认事实，用户主动明确提及主题后才唤回，不主动催促唤醒。
- FR06-35：进展只复制成功完成回复对应的真实 USER 消息，不超过现有 240 字符限制；问题、假设、情绪与敏感内容不得成为进展。
- FR06-36：确认、替代、删除、进展写入采用行锁/事务和版本校验；锁顺序固定并覆盖并发测试，失败不得部分替代。
- FR06-37：跨端和语音操作共享服务端状态；网页传入 deviceId 只允许已经绑定的记忆管理范围，不能触发实体操作。
- FR06-38：所有新增写入口遵循公共幂等键与 resourceVersion；同键不同内容 409，旧 API 的原有调用保持兼容。
- FR06-39：替代候选固定沿用原role/device/scope/category，标题最多120字符、正文最多2000字符、reason最多240字符；普通纠正候选不得擅自改变范围或类别。
- FR06-40：新内容默认allowProactiveMention=false；需要继续待续时确认页明确重述“相关聊天接续并保存明确进展”的许可。旧许可不得隐式复制到变更内容，旧停止/暂停也不得被替代动作静默解除。

## 5. 数据与接口增量

现有 MemorySnapshot 已有确认、启用、来源、topicKey、替代链、allowProactiveMention、possibleDuplicateIds。
V57 待续字段与预算表由 R00 整合，实施本需求不得重新占用 V57 或修订已发布迁移。
下面为拟新增接口；可以扩展现有控制器服务，但新路径统一 /api/v1/companion。

| 拟新增 API | 输入/输出与守卫 |
| --- | --- |
| POST /api/v1/companion/memories/{id}/corrections | expectedUpdatedAt、title、content、reason；幂等键；输出 PENDING 候选、旧新版本、expiresAt与明确许可选项，不直接 CONFIRMED |
| POST /api/v1/companion/memories/{id}/corrections/{candidateId}/confirm | candidateUpdatedAt、oldMemoryUpdatedAt、明确内容快照；事务确认；失效返回 409/410 |
| GET /api/v1/companion/memories/{id}/provenance | 返回授权范围内来源类型、日期、原始对象引用、替代关系与许可说明，不返回凭据 |
| GET /api/v1/companion/context-preview | 仅管理员诊断；device/role、可选 goal；返回来源 ID/类型/有效性与裁剪原因，默认不导出正文 |

建议增量纠正状态：PENDING、CONFIRMED、REJECTED、EXPIRED、INVALIDATED；若复用现有提案状态，应给映射而非第二套并行状态。
新字段 memoryContextReason 只能是固定枚举，如 DIRECT_TOPIC、ALIAS_TOPIC、RECENT_REFERENCE、EXPLICIT_GOAL；不能保存模型自由解释。
纠正候选创建时服务器计算expiresAt=createdAt+120秒；确认按钮同时核对候选与旧事实版本。目标预算变化须另走R03修订，纠正个人记忆不会隐式改目标。
所有版本时间戳使用服务器原始ISO8601值，不由浏览器重新格式化后比对；缺字段400，旧对象变化409，确认过期410，源对象已删除404/INVALIDATED按现有包装返回。
候选版本优先复用现有 updatedAt；新增 resourceVersion 只对新增资源使用，不让前端猜旧记录版本。
删除写入源关联、候选 invalidation 与普通主动撤销必须在同一个明确事务边界完成；缺关联信息采用保守清理。
所有候选正文仍走敏感过滤；日志仅 ID、状态、固定原因和长度，不记录旧新个人事实正文。
现有时间展示使用设备 IANA 时区；日预算继承公共时区修改规则，不通过改时区多造建议。

## 6. 页面与语音文案

保留「我的伙伴 → 记忆」列表与详情入口；使用现有 Fa 组件，不新增一套记忆应用。
在详情展示「来源」「记录时间」「当前有效事实」「待续状态」「允许主动提起」；权限分别解释。

| 条件 | 精确文案 | 操作与结果 |
| --- | --- | --- |
| 待确认纠正 | “这条记忆要从以下内容改为新内容吗？” | 并排或手机上下展示“原内容”“新内容” |
| 长期确认主按钮 | “确认替换” | 原子生效；不能只保存表单而未替代旧事实 |
| 次操作 | “暂不修改” | 候选拒绝/关闭；原事实保留 |
| 旧事实已经更新 | “原记忆已变化，请重新核对。” | 保留用户输入、刷新旧新差异，不自动重试确认 |
| 旧候选已失效 | “这次确认已失效，请查看最新记忆。” | 不显示成功，不恢复旧候选 |
| 来源会话已删除 | “来源对话已删除，相关进展已清除。” | 原确认事实单独显示，说明可另行删除 |
| 用户本轮纠正 | “明白，这次按你刚说的来。” | 不声称长期保存已经完成 |
| 没有唯一记忆对象 | “你想修改哪条记忆？” | 给授权范围内最多 3 个标题供选择 |
| 暂停待续 | “这件事今天先不聊。” | 标“暂停至明天”；使用设备本地日期 |
| 持续停止 | “我不再提这件事。你想继续时再说。” | 标“已停止”，恢复入口明确 |
| 休眠主题 | “休眠：等待你主动提起” | 不用“你很久没来看我了” |
| 无相关资料 | “我还没有足够的背景，你可以告诉我具体是哪件事。” | 不引用无关记忆填空 |
| 检索临时失败 | “记忆暂不可用” | 控制台错误可重读；普通聊天不被阻塞 |

不显示关系等级、亲密度、自动心理标签，不以“我永远不会忘记”承诺超出删除与保存策略的能力。

## 7. 验收场景

至少构建 30 组带正确答案的有限样例；下面的安全场景全部通过，不能被平均准确率抵消。

| ID | Given | When | Then |
| --- | --- | --- | --- |
| AC06-01 | 旧已确认记忆，主动/待续许可为无 | 升级含 V57 和新增策略 | 仍为普通记忆，不自动获得主动或待续许可 |
| AC06-02 | 同主题 PENDING 候选 | 用户普通聊天 | 不召回候选为事实，也不自动开卡 |
| AC06-03 | 允许保存但未允许主动提起 | 主动来源生成 | 不引用该事实开口；相关用户聊天可按许可使用 |
| AC06-04 | 用户A伙伴确认偏好 | 切到B伙伴询问 | 不引用A事实、标题或进展 |
| AC06-05 | 已确认咖啡偏好 | 用受支持同义“coffee”询问 | 有界命中同一事实；无关“方案”不泛命中所有计划 |
| AC06-06 | 两个待续主题同分 | 用户说“那个计划” | 询问具体对象，不选最新或重要性最高者 |
| AC06-07 | 当前明确说预算800，旧记忆500 | 本轮回答 | 按800处理，旧长期事实未自动更改 |
| AC06-08 | 明确要求修改长期预算 | 生成候选但未确认 | 旧事实仍有效；候选列出500→800 |
| AC06-09 | 合法替代候选未过期 | 确认替换 | 新事实确认与旧事实退出同一事务，不双重有效 |
| AC06-10 | 旧记忆在候选后已编辑 | 确认旧候选 | 返回冲突，不覆盖新编辑，要求重核 |
| AC06-11 | 同一候选已确认 | 相同幂等重试 | 返回原结果，不新增记忆、不重复替代 |
| AC06-12 | 主题已停止 | 午夜或角色切回 | 不恢复；明确“继续聊X”才恢复 |
| AC06-13 | 主题暂停当天 | 次日到达且用户相关提及 | 可按既有许可接续；不产生定时主动消息 |
| AC06-14 | 14天未有用户进展 | 进入相关聊天 | 标休眠；仅用户主动提起主题后恢复 |
| AC06-15 | 真实用户进展≤240字符且成功完成回复 | 记录讨论 | 保存来源引用与进展；问题/假设不保存 |
