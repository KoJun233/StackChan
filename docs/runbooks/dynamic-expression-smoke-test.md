# 动态球形表情实机验收

## 适用范围

用于 `MEDIA-002` 的 LAN HTTP CoreS3 成功路径。该流程不包含回退演练、NVS 清除、串口整片刷写或生产部署。

## 前置确认

- 确认目标设备为 CoreS3，运行 `motion_disabled` 且应用 OTA 可用。
- 确认任务提交、LAN HTTP Quad profile、固件版本、SHA-256 和制品大小。
- 确认制品使用 ESP-IDF 5.4.4、官方 `m5stack_core_s3` BSP 4.0.0、LVGL 9.4，依赖锁和固件硬件实现均不再引用 M5Unified/M5GFX。
- 明确选择应用 OTA 并保留 NVS；未获得本次设备操作授权则停止。
- 当前 server 必须已应用 V33，并在健康中心识别 `dynamicExpressionSupported=true`。

## `41b8827-perf9` 已确认基线

- 用户通过 LAN HTTP Quad 应用 OTA 安装并保留 NVS，未执行回退演练。
- 固定 60 FPS 待机实测约 55 FPS：场景更新 1041 μs、LVGL 刷新 11077 μs、锁等待 462 μs、音频 underrun 0、最低空闲堆约 7.56 MiB。
- 用户确认画面流畅度、唤醒、回答播放和音量正常；该结果接受为 40 MHz SPI 下的稳定成功路径。
- 尚未明确记录的固定 47 FPS、自适应 24–57 FPS、PNG 兼容、IMU 摇晃和连续三十分钟场景仍按下列步骤补充，不能从上述确认中推断为已通过。

## 成功路径

1. 通过应用 OTA 安装提交绑定的固件，等待状态进入 `INSTALLED`；确认设备身份、网络、唤醒模型和 `motion_disabled` 保留。
2. 确认启动日志显示官方 CoreS3 BSP 的 LVGL 显示/触摸、Codec 音频与 BMI270 已初始化；在未启用 PNG 表情包时确认屏幕显示 160×160 无嘴动态球体，健康中心显示“动态球体”、目标/实际 FPS、`imu=true` 和 `proximity=false`。
3. 在“表情与角色形象”依次保存固定 47 FPS、固定 60 FPS 和滑块选择的 24–57 自适应，确认滑块可逐个整数选择且重载后保持原值；记录实际 FPS、降帧原因、丢帧、最低堆水位和是否重启。确认场景更新、LVGL 刷新和锁等待不再停在 `65535 μs`，并以场景更新与 LVGL 刷新之和判断总帧预算；固定 60 允许实际值低于目标，但不得引起音频 underrun 或重启。播放期间临时限制实际视觉提交时必须显示 `AUDIO_BUSY`，停止播放后恢复配置目标；自适应降帧必须仍位于 24–57 范围内并出现对应原因。
4. 分别触发倾听、思考、说话、完成、错误模拟和离线/重连，确认过渡连续且系统状态覆盖角色情绪。
5. 使用两个不同主题色的角色各完成一轮语音对话，确认轨道/粒子点缀色随角色切换和设备重连恢复，默认奶油色身体不被整球染色；情绪标记不得出现在文字、语音或历史中。
6. 验证 12 种情绪及弱/中/强至少各一组，5–15 秒后回归中性；覆盖结束只恢复尚未过期的底层情绪。
7. 在管理页点击 12 种情绪、9 种交互/系统表现和 6 种行为的预览按钮，确认设备显示对应语义并在五秒后恢复；真实说话、离线、错误或更新状态不得被预览覆盖。启用静态 PNG 后按钮必须禁用。
8. 轻触屏幕确认喜爱短时反应，按住/松开边沿各只触发一次且 LVGL 刷新繁忙时不产生误释放；轻摇设备确认 BSP BMI270 的眩晕反应。不得把没有硬件支持的接近行为记为成功。
9. 先在静音环境连续完成十次唤醒，记录成功次数和误触发；再完成至少三个完整对话回合。播放语音时观察降帧，必须能听到回答且无爆音/断裂，触摸取消继续有效，`audioUnderruns` 不新增。若服务端已记录 `PLAYBACK_COMPLETED` 但设备无声，同样判定失败。
10. 启用一个既有 PNG 表情包，确认静态表情仍可显示且健康中心切换为“静态 PNG”；清除资源包后回到动态球体。
11. 连续运行三十分钟，确认无重启、无持续堆下降，并保存不含正文、音频和秘密的诊断结果。

## 失败停止条件

- OTA 失败、设备身份或 NVS 丢失、运动安全状态改变。
- 音频出现新增 underrun、连续异常降到 20 FPS且无原因、最低堆持续下降或设备重启。
- 系统状态被模型情绪覆盖、角色颜色在角色间串用、情绪标记被朗读或写入历史。
- BSP 显示、触摸、麦克风、扬声器或 BMI270 任一初始化失败，或运行时回到旧硬件路径。

出现任一条件时停止继续测试，保留当前运行版本和安全诊断，不自动执行回退或清除 NVS。
