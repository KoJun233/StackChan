# 宠物表情资源包生成与验收

本 runbook 用于 INT-007 的八状态资源包。管理端入口为“陪伴交互 → 宠物表情包”。当前生成链路不调用固定的云端图片供应商：可以使用任意有权使用的 AI 绘图或设计工具准备图片，再由 StackChan 服务端完成可信打包。

## 一、准备统一角色基准

先确定角色的物种/材质、主色、眼睛、脸部轮廓、背景和光照。八张图必须使用同一角色、相同构图、相同镜头与背景；推荐固定参考图、随机种子和风格描述。

通用提示词模板：

> 同一个正面宠物机器人头像，角色设定为「角色描述」，居中、头部占画面约 70%，纯色深背景，清晰轮廓，高对比度，无文字、无徽标、无边框，320×240，保持角色身份和镜头完全一致。当前状态：「状态描述」。

建议输出不透明 RGB/RGBA PNG。不要在图片里加入状态文字；离线和异常也不能画成与正常交互相同的颜色。

## 二、生成八个稳定状态

| 文件/字段 | 状态描述 | 视觉验收重点 |
| --- | --- | --- |
| `idle` | 放松待机，轻微微笑，目视前方 | 中性且适合长时间显示 |
| `listening` | 专注聆听，眼睛张开，青蓝提示光 | 与处理中明显不同 |
| `processing` | 正在思考，视线偏移或琥珀提示光 | 不得像离线或错误 |
| `speaking` | 愉快播报，嘴部张开或粉色声波提示 | 能直观看出正在说话 |
| `success` | 开心、确认完成，绿色积极反馈 | 不与待机混淆 |
| `no_speech` | 温和疑惑/没听清，青色弱反馈 | 不能表现为严重故障 |
| `offline` | 安静休眠，中性灰、低活跃 | 不使用聆听态蓝色 |
| `error` | 可恢复的小故障，橙色警示、仍友好 | 不使用危险红屏或恐怖图案 |

## 三、导出约束

- 每张必须是可完整解码的 PNG，尺寸精确为 `320×240`。
- 8-bit RGB、调色板或 RGBA；单张不超过 `384 KiB`。
- 八张合成后的制品不超过 `1.5 MiB`。
- 不上传没有使用权、包含秘密、人物隐私或认证信息的图片。

管理端会在浏览器先检查 MIME、尺寸和大小；服务端再次真实解码，并校验八状态完整性、尺寸、格式、逐图 SHA-256 和最终制品 SHA-256。任一项失败都不会生成资源包。

## 四、生成与切换

1. 选择目标机器人，填写资源包名称和版本说明。
2. 为八个状态分别选择图片，确认卡片预览中的角色与配色一致。
3. 点击“生成资源包”。生成成功只表示服务端制品已通过校验，尚未改变设备。
4. 在资源包列表点击“启用”。在线设备会下载到非活动槽并完整校验，成功后原子切换；离线设备保留 `READY`，重连后自动继续。
5. 状态显示 `ACTIVE` 后，按下方 smoke test 完成人工验收。

## 五、设备 smoke test

依次确认：

1. 在线待机显示 `idle`，五分钟后屏保仍是低亮度内置机械眼且触摸可恢复。
2. 唤醒后依次看到 `listening`、`processing`、`speaking`，完成后显示 `success` 并回到待机。
3. 唤醒后不说话显示 `no_speech`。
4. 暂时断开服务端显示 `offline`，恢复连接后回到待机。
5. 制造一次可恢复错误显示 `error`，下一轮正常交互可恢复。
6. 停用资源包后立即恢复内置机械眼；设备重连后仍保持默认表情。

未经用户明确确认，不得为本 runbook 刷写固件、部署服务或修改运行凭据。

## 六、删除与恢复

- 启用中的资源包必须先停用，停用命令会恢复默认表情并擦除设备 A/B 资源槽。
- 离线设备会在下次重连时收到幂等清理命令。
- 删除资源包会级联删除服务端八张预览图和下载制品，不能撤销；需要保留时先在自己的受控目录保存源图。
- 下载失败、摘要不一致、清单损坏、图片损坏或掉电均不得覆盖内置默认表情。
