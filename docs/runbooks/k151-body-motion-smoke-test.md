# K151 安全身体感实机验收

本流程只用于 BODY-001 候选。服务端和页面发布不授权固件安装或实体动作；开始前必须分别确认目标 CoreS3、串口、传输 profile、候选提交、保留 NVS 策略和本次允许执行的动作。

经明确授权进行本地实体诊断时，可以通过 CoreS3 的 USB Serial/JTAG 发送单行 `{"type":"calibrate_body_center"}`。该入口严格拒绝额外字段，只复用第 2 步的断扭矩反馈校准，不提供动作启用、模板、角度、速度或循环参数；语音、升级或设备错误期间返回拒绝状态。它只用于免浏览器复现和采集阶段日志，不扩大后续动作授权。

按需开启舵机电源后必须至少等待 1200 ms，再发送断扭矩写入并读取两路位置反馈。K151 的 VM 由底座电池经升压轨产生；诊断可使用 INA226 只输出 `present/low/absent/unavailable` 分类，但不得记录或上传原始电压、电流和舵机位置。

## 前置条件

- 使用与运行服务端匹配的 K151/CoreS3 固件；不得在非 K151 硬件上尝试。
- 机器人放在稳定桌面，头部周围至少留出 30 cm 空间，USB 线不会牵拉头部。
- 首次校准时用手把头部放在期望的正前方中位；校准期间不要扶住或推动头部。
- 页面必须先显示 `motion_disabled`。若上电即运动、持续用力、异响或发热，立即断开电源并停止验收。
- 不记录原始舵机位置、原始接近/照度、凭据或完整协议载荷。

## 分阶段验收

1. 只安装候选并启动，不点击校准或启用。确认显示和语音正常、设备在线，心跳能力与实物一致，头部完全不动，安全状态为“已禁用”。
2. 用手摆正头部，点击“校准当前中位”。确认没有主动位移；下一次心跳显示“已校准中位”。若反馈不可用，页面应保留禁用且显示 `FEEDBACK_FAULT`。
3. 点击“显式启用动作”。确认此步骤只做反馈探测且头部不主动位移；下一次心跳显示“已启用/反馈正常”。重启设备，确认再次回到“已禁用”而校准状态仍保留。
4. 再次显式启用，只执行 `NOD_SMALL`。确认动作幅度小、无越界、在限定时间内回到中位并断开保持力。
5. 逐个执行 `LOOK_USER`、`THINK`、`DROWSY`、`WAKE`，每次之间等待状态回到 `ARMED`。任一异常立即停止，不继续其他模板。
6. 动作期间触摸顶部，确认动作立即停止、舵机失去保持力、状态回到“已禁用”，失败码为 `TOUCH_STOP`。重新校准不是自动动作；只有确认机械位置合适后才可再次启用。
7. 动作期间开始语音回合或播报，确认声音优先、动作停止并禁用；音频完成后不得自行恢复动作。
8. 断开 WebSocket 或 Wi-Fi，确认当前动作停止且离线期间任何页面命令都不能排队后执行。
9. 重启一次，确认默认禁用、没有启动动作、语音和表情仍可用。

## 通过标准

- 无启动运动、越界、持续运动、持续保持力、异响、发热或自动重启。
- 五个模板只能逐个执行并在有界时间内结束；任意参数化动作不存在。
- 顶部触摸、语音、离线、超时或反馈错误均由设备本地停止并禁用。
- 页面只显示能力、布尔在场、环境光分档和安全失败；服务端无原始传感器数据。

任何一项失败都不标记 BODY-001 实机通过。保留失败码、时间、候选版本和非秘密现象描述即可；重新刷写或扩大动作范围需要新的授权。
