# EAF 生命周期资源包实机验收

## 前置边界

- 只使用 LAN HTTP development profile；公网环境必须 HTTPS。
- 固件、目标设备、保留 NVS 和 OTA 成功路径必须逐次取得用户确认。
- 不做回退演练，不清理 NVS，不启用运动。
- 测试素材必须符合[表情资源包 V2](../protocol/expression-pack-v2.md)，不得包含秘密或用户数据。

## 自动化门槛

1. 服务端全量测试通过，空库 Flyway 应用到 V36。
2. 控制台测试、类型检查和生产构建通过。
3. protocol 与 LAN HTTP Quad 固件构建通过，并记录尺寸和 SHA-256。
4. `git diff --check` 与 `pnpm docs:check` 通过。

## 页面验收

1. 打开“表情与角色形象”，选择“生命周期动画”。
2. 上传至少一个 EAF，可分别设置 16..100 ms 帧间隔；非法签名、超限文件和超时片段必须被拒绝。
3. 创建后在管理列表确认类型、片段名、帧数、间隔、大小和摘要。
4. 不支持该能力的设备不能启用 V2；支持设备可启用、停用和删除。
5. V2 激活时，原生情绪/状态预览按钮仍可使用；V1 静态 PNG 的兼容行为不变。

## 实机成功路径

1. 保留 NVS 完成应用 OTA，确认设备在线并上报 `lifecycle_clips_supported=true`。
2. 启用含 `boot_appear`、`wake`、`role_switch` 的 V2 包。
3. 重启：开机片段播放一次，结束后恢复原生动态球体。
4. 唤醒：唤醒片段播放一次；进入监听/处理/说话时不得遮盖相应原生状态。
5. 页面切换角色：角色切换片段播放一次，角色主题色和会话隔离保持正确。
6. 连续执行三次语音对话，并在 TTS 中触摸取消；确认声音、下一回合、帧率和音频 underrun 无回归。
7. 停用 V2 包，确认无需重启立即回到纯原生渲染。

## 失败路径

- 下载、总摘要、manifest、片段摘要或 EAF 结构校验失败时不得切换活动槽。
- 安装失败继续使用旧槽；播放失败只跳过当前片段并恢复原生渲染。
- 记录安全失败码、设备在线状态、帧率/堆诊断和是否自动重启；不记录资源正文、令牌或认证载荷。
